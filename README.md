# CodeSolve Platform

مرحباً بك في مستودع منصة CodeSolve الرسمية.
هذا المشروع مبني باستخدام React.js و Vite و Tailwind CSS ضمن معايير أداء وهندسة عالية.

## المتطلبات الأساسية
- Node.js (الإصدار 18 فما فوق)
- npm أو yarn

## تعليمات التشغيل محلياً
1. تثبيت الحزم:
   ```bash
   npm install
   ```
2. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```

## الاستضافة والإطلاق (Deployment)
⚠️ **تنبيه هام جداً**: 
أمر البناء أدناه مخصص **حصراً** لتوليد ملفات الويب الثابتة (Static Web Files) داخل مجلد `dist`، ليتم رفعها على منصات الاستضافة السحابية مثل Vercel، Netlify، أو استضافات الويب التقليدية. 
**لا يوجد أي ملفات تنفيذية (Executable Installers) ولا يجوز إطلاق أي أوامر بناء برمجيات سطح مكتب أو ملفات تثبيت.**

أمر البناء للاستضافة:
```bash
npm run build
```

بعد البناء، يمكنك تجربة النسخة المبنية محلياً عبر:
```bash
npm run preview
```
